# Gestion de Base de Données de Contacts et d'Interactions
# Projet CDAA - Conception et Développement Avancé d'Applications
    Ce projet a été réalisé dans le cadre du cours de Conception et Développement Avancé d'Applications (CDAA) en troisième année de Licence Informatique. L'objectif est de développer une application de gestion de base de données de contacts et d'interactions, s'inspirant des fonctionnalités d'un CRM (Customer Relationship Management).

# Technologies Utilisées
    Langage : C++
    Framework : Qt
    Base de données : Intégration avec des structures de données pour stocker les informations.

# Fonctionnalités Principales
    # Gestion des Contacts
    Ajout, modification et suppression de contacts.
    Visualisation des détails de chaque contact (nom, prénom, email, etc.).
    Filtrage et recherche avancée des contacts.
    # Gestion des Interactions
    Association d’interactions à des contacts spécifiques.
    Gestion des dates et des descriptions pour chaque interaction.
    Suivi des interactions passées.
    # Recherche et Organisation
    Recherche des contacts et interactions à l'aide de critères spécifiques.
    Tri des données selon divers attributs (date, nom, etc.).

# Structure du Projet
    - Modèle (Model) : Gestion des données des contacts et interactions.
    - Vue (View) : Interfaces graphiques conçues avec Qt pour une interaction utilisateur intuitive.
    - Contrôleur (Controller) : Logique métier assurant la liaison entre les données et les interfaces.

# Apprentissage et Objectifs
    Ce projet a permis de :
    
    - Maîtriser les concepts avancés de développement en C++.
    - Découvrir et utiliser le framework Qt pour créer des interfaces graphiques modernes et performantes.
    - Implémenter des structures de données efficaces pour gérer et organiser les informations.
    - Développer des compétences en architecture logicielle orientée objet.
